PLANNER NODE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
    LLM called with SYSTEM_PROMPT + user message
    temperature=0.0 → deterministic decision
    returns JSON:
        action: "retrieve" | "direct_answer" | "tool_use"
        refined_query: standalone rewritten query
        reasoning: why this action
    
    state updated:
        current_query = refined_query
        plan = [reasoning]
        action = "retrieve" / "direct_answer" / "tool_use"
    
    client receives NDJSON:
        {"type": "status", "node": "planner"}
    ↓
conditional edge routes based on action:

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
PATH A — "retrieve" (most common)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
RETRIEVER NODE
    Ray embed_client.embed_query(current_query)
        → HTTP call to Ray Serve embed service
        → BGE-M3 model generates 768-dim vector
    
    asyncio.gather() fires both searches simultaneously:
    
    Qdrant search:
        HNSW cosine similarity search
        top 5 chunks returned
        formatted as "text [Source: filename, Page: N]"
    
    Neo4j search:
        LLM extracts entities from query (temperature=0.0)
        fixed Cypher query runs against entity_index
        traverses one hop to find relationships
        returns "Entity → RELATIONSHIP → Neighbor" triples
    
    results merged, deduplicated
    state["documents"] updated with combined chunks
    
    client receives NDJSON:
        {"type": "status", "node": "retriever"}
    ↓
RESPONDER NODE
    context_str = all documents joined
    LLM called with:
        system: "You are Enterprise Assistant, cite sources"
        user: context + question
        temperature=0.3
    
    answer streams back from Ray LLM service
    (vLLM serving Llama 3 70B, AWQ quantized)
    (max_num_seqs=128 concurrent requests per GPU)
    
    state["messages"] appended with assistant answer
    
    client receives NDJSON:
        {"type": "status", "node": "responder"}
        {"type": "answer", "content": "Our refund policy..."}

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
PATH B — "direct_answer"
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
    skips retriever entirely
    goes straight to responder
    LLM answers from conversation history alone
    (used for greetings, clarifications, follow-ups)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
PATH C — "tool_use"
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
    TOOL NODE dispatches based on tool_choice:
    
    "calculator"   → simpleeval AST parsing → no exec(), safe math
    "graph_search" → entity extraction → fixed Cypher → Neo4j
    "vector_search"→ embed → Qdrant search → top 3 docs
    "web_search"   → Tavily API → top 3 real-time results
    "sandbox"      → HTTP POST to sandbox container
                     Flask spawns subprocess
                     SIGTERM at 5s, SIGKILL at 7s
                     stdout captured, returned
                     (non-root user, no network egress,
                      CPU/RAM limits enforced by K8s)
    
    tool result added to messages as "Tool Output: ..."
    goes to responder → formats into natural language answer
    ↓
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
POST PROCESSING (all paths)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
    final_answer captured from responder node
    ↓
    PostgreSQL:
        add_message(session_id, "user", user_message, user_id)

    ↓

    uuid4() generated → unique file_id
    s3_key = uploads/{user_id}/{file_id}.pdf

    boto3 generates presigned PUT URL
        locked to this s3_key
        locked to this content_type
        expires in 1 hour
    ↓

    ↓
    browser PUT 500MB PDF directly to S3
    (API server never touches the file)
    Transfer Acceleration routes via nearest AWS edge
    ↓
    browser notifies API → triggers ingestion pipeline
    ↓

INFRASTRUCTURE SCALING (continuous)

        FastAPI pod count increases
        Karpenter cpu-provisioner launches Spot m6i nodes (~60s)
        Ray scales GPU workers up
        Karpenter gpu-provisioner launches g5 instances (~90s)
    
    traffic drops at 3am:
        Ray scales GPU workers to 0
        Karpenter terminates GPU nodes after 30s TTL
        Karpenter consolidates CPU pods → kills empty nodes
        Aurora scales from 64 ACUs → 2 ACUs automatically
        cost drops to near zero overnight
